### 🏠 [Vero Homes](https://vero-homes.vercel.app) — Nigerian Real Estate Platform
> A fullstack property listing platform built for the Nigerian market.

- Property listings with interactive map integration (Leaflet)
- Secure authentication with NextAuth.js (credentials + session management)
- Image uploads and optimization via Cloudinary
- MongoDB Atlas database with Mongoose schema modeling
- Built with **Next.js 15 App Router · TypeScript · Tailwind CSS · MongoDB**

---

### 📈 [ForexPro](https://forexpro.vercel.app) — Forex Trading Dashboard
> A multi-user trading dashboard with live market data and news.

- Live forex rates from Twelve Data API
- Interactive candlestick and line charts with Recharts
- Real-time financial news feed via NewsData.io
- Protected routes and multi-user session handling
- Built with **Next.js · TypeScript · MongoDB Atlas · Recharts · Tailwind CSS**
