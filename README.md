## 👨🏽‍💻 About Me

I'm a self-taught software developer with a Computer Science and Robotics Education background who became interested in software engineering through building real applications.

I enjoy working across the stack, but I'm particularly interested in **backend engineering** — designing APIs, modeling data, handling authentication and authorization, building asynchronous workflows, integrating third-party services, and connecting distributed parts of an application reliably.

Currently focused on building and improving production-style applications with **Node.js, TypeScript, Express, MongoDB, REST APIs, Socket.IO, and modern React/Next.js**.

I'm also currently expanding my skills in **Python, React Native/Expo, Redis, queues, and system design**.

## 🚀 Featured Projects

### 🎧 [ServiceDesk](https://github.com/abdul-p/Service-Desk) — Multi-Tenant Customer Support SaaS

> **Omnichannel Support, Reimagined.**

A multi-tenant customer support platform built around real-time communication between customers and support teams.

**Highlights**

* Multi-tenant architecture with company-level data isolation
* RBAC for **Admin, Agent, and Customer** roles
* JWT-based authentication and authorization
* Real-time customer/agent communication with **Socket.IO**
* Ticket creation, assignment, status workflows, and SLA tracking
* Company-based agent routing and ticket queues
* Customer profiles and support context
* Separate customer and agent Socket.IO namespaces
* Internal escalation workflows for departments such as billing, engineering, compliance, and legal
* REST APIs for ticket and support operations
* Demo Mode with simulated agent responses for frontend development

**Stack:** `Node.js` · `Express` · `MongoDB` · `Mongoose` · `React` · `Socket.IO` · `JWT` · `RBAC` · `REST APIs`
